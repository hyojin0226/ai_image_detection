실험 결과 원본 보기 ↗
실험을 어떻게 설계했나요?＋
  1. 같은 사진과 영상 묶음을 분리했습니다.중복 사진을 제거하고, 같은 사진이나 같은 영상의 프레임이 학습·검증·테스트에 나뉘어 섞이지 않도록 구성했습니다.
  2. 생성기 계열 하나를 학습에서 제외했습니다.GAN, diffusion, 얼굴 조작(manip) 중 하나를 빼고 학습한 뒤, 제외한 계열로 테스트했습니다. 이를 LOGO 평가라고 합니다.
  3. 파일 형식 단서를 줄였습니다.학습 시 JPEG 품질 60~95, 평가 시 품질 90으로 재인코딩했습니다. 기존 압축 흔적까지 완전히 제거할 수는 없습니다.
  4. 세 모델을 같은 조건에서 비교했습니다.EfficientNetV2S, ConvNeXt-T, CLIP + 선형 분류기를 비교하고, 각 판정 기준은 검증셋에서 정한 뒤 테스트에 그대로 적용했습니다.
이전 정확도 97.8%는 무엇이 달라졌나요?＋

1차 ID 테스트 정확도 97.8%, ROC-AUC 0.998은 당시 평가셋의 결과입니다. 이후 조사에서 테스트의 실제 사진 73%, AI 사진 32%와 같은 사진이 학습에도 포함된 것으로 확인됐습니다. 따라서 이 수치를 실사용 정확도나 새로운 생성기에 대한 성능으로 볼 수 없습니다.

FLUX·SDXL도 학습에 포함되어 있어, 기존의 99.6% 결과는 미학습 생성기 평가가 아닙니다. 파일 내용이 같아도 재인코딩으로 바이트가 달라질 수 있어, 파일 중복 검사만으로는 이 문제를 찾지 못했습니다.

어떤 사진에서 주의해야 하나요?＋
  • 얼굴 사진용 모델입니다. 풍경·사물·전신 사진이나 얼굴이 작은 사진에는 적합하지 않습니다.
  • 1차 모델의 GRAVEX 분석에서는 FaceForensics++ 부분 조작 이미지 291장 중 286장(98.3%)을 놓쳤습니다. 이 특정 평가의 결과이며 모든 영상에 대한 수치가 아닙니다.
  • 압축·축소가 강해지면 실제 사진을 AI로 오판하는 경우가 늘었습니다. 가능하면 원본으로 확인하세요.
  • 1차 강건성 평가에도 중복 문제의 영향이 있어, 절대 성능보다 변환 전후의 차이를 참고해야 합니다.

결과 읽는 법

분류 결과와 사진의 실제 출처는 다를 수 있습니다.

REAL과 AI는 모델의 분류입니다

REAL

실제 얼굴 사진 범주로 분류했다는 뜻입니다. 촬영 사실, 인물의 신원, 보정 여부까지 확인한 결과는 아닙니다.

AI

AI 생성 얼굴 범주로 분류했다는 뜻입니다. 생성 프로그램이나 제작자를 알아낸 것은 아니며 실제 사진도 잘못 분류할 수 있습니다.

영상은 어떻게 판단하나요?

3~40초 영상에서 길이에 따라 16·32·48·64프레임을 추출합니다(10초 이하 16, 20초 이하 32, 30초 이하 48, 그 이상 64). 이미지 모델의 특징을 영상 전용 분류기로 모아 판정하며, AI 점수가 0.5 이상이면 AI 생성으로 분류합니다. 사진의 REAL 기준값 0.16과는 다릅니다. 구간별 점수와 프레임의 Grad-CAM은 판단을 살펴보는 자료이며, 위조 위치나 정답의 증거가 아닙니다.

왜 사진은 50%가 아닌 0.16을 기준으로 하나요?

현재 사진 모델은 REAL 점수 하나를 출력합니다. 설정된 기준선 0.16 이상은 REAL, 미만은 AI로 표시합니다. 두 범주의 숫자 중 큰 값을 고르는 방식이 아닙니다.

예: REAL 0.20 / AI 0.80 → REAL 분류

REAL 0.20이 기준선 0.16 이상이기 때문입니다. 설명을 위한 예시이며 업로드한 파일의 결과가 아닙니다.

이 점수를 해당 사진에 대한 정답 확률로 해석하면 안 됩니다. 기준선과의 거리만으로 신뢰도 등급을 만들 수도 없습니다.

예상과 다른 결과가 나왔다면

  1. 지원 대상을 확인하세요.현재 모델은 얼굴 이미지용입니다. 풍경·사물·문서 사진에 나온 숫자를 진위 판정에 사용하지 마세요.
  2. 가능하면 원본으로 다시 확인하세요.스크린샷, 재저장, 필터·보정에 따라 입력이 달라집니다. 원본과 편집본의 결과 차이 자체가 조작의 증거는 아닙니다.
  3. 최초 게시물과 제작 경로를 확인하세요.게시 날짜, 원본 파일, 촬영·제작 설명 등 별도의 정보를 함께 확인하세요. 탐지 결과만으로 타인의 제작 과정을 단정하지 마세요.
다른 파일 분석

분석 화면에서 볼 수 없는 것

분류 점수는 사진 전체에 대한 결과입니다. Grad-CAM은 AI 판정에 영향을 준 영역을 보여주지만 위조된 부위를 찾아낸 결과가 아닙니다. 사용한 생성기나 생성 시각은 알아낼 수 없고, REAL 판정도 부분 조작이 없다는 보장이 아닙니다.

현재 구현에서 어디에 어떤 정보가 남는지 안내합니다.

분석한 사진

파일은 이 브라우저에서 분석하며 Fakit 서버로 업로드하지 않습니다. 모델과 화면에 필요한 라이브러리·글꼴을 내려받을 때는 네트워크 연결을 사용합니다.

이미지 주소로 가져오기를 누르면 원본 이미지 호스트에 요청이 전달됩니다. 확장 프로그램은 선택한 이미지 주소만 Fakit으로 전달하며 페이지 전체나 로그인 쿠키를 수집하지 않습니다.

분석 기록

  • 파일명, 축소 미리보기, 결과 점수, 판정 기준선, 분석 시각, Grad-CAM과 영상 프레임 결과가 이 브라우저에 저장됩니다. 축소 이미지에도 얼굴 등 식별 가능한 정보가 남을 수 있습니다.
  • 최대 200건 또는 계정당 약 64MB를 보관하며 초과하면 오래된 기록부터 제외합니다.
  • ‘기록 저장’을 끄면 이후 기록을 저장하지 않습니다. 이미 저장된 기록까지 지워지지는 않습니다.
  • 로그인한 계정의 기록은 이 브라우저에서 암호화되며 같은 계정으로 다시 로그인하면 볼 수 있습니다. 게스트 기록은 같은 브라우저의 게스트 모드에 남습니다.
  • 기록 페이지에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 삭제 후 복구 기능은 없습니다.

소셜 로그인

카카오·구글에서 계정 식별자와 표시 이름을 받아 로그인 상태를 관리합니다. 로그인했다고 이미지 기록이 계정에 업로드되거나 다른 기기로 동기화되지는 않습니다.

로그인 상태는 암호화된 보안 쿠키로 최대 8시간 유지합니다. 제공자의 접근 토큰은 프로필 조회 후 보관하지 않습니다. 로그아웃하면 이 브라우저의 로그인 쿠키를 지웁니다. 서비스 로그아웃은 제공자 계정 연결 해제와 다릅니다.

사용 방법과 문제 해결

파일 선택, 붙여넣기, 이미지 주소 가져오기를 지원합니다.

이미지 올리는 세 가지 방법

드래그

끌어다 놓기

탐색기나 다른 창에서 사진을 파일 입력 영역에 끌어다 놓으면 됩니다. 여러 파일을 놓으면 최대 20개 파일을 순서대로 검사합니다.

붙여넣기

Ctrl + V

화면 캡처(Win+Shift+S)나 복사한 이미지를 페이지에서 바로 붙여넣습니다. 입력창 안에서도 이미지 붙여넣기를 지원합니다.

업로드

이미지 선택

입력창 왼쪽 + 버튼으로 파일을 고릅니다. 한 번에 최대 20개, 이미지당 15MB까지 검사합니다.

파일을 구분하는 방법

같은 입력창에서 파일 종류를 확인합니다. 사진은 JPG·PNG·WEBP 얼굴 이미지를 지원합니다. MP4·WebM 영상은 3~40초·90MB 이하를 브라우저에서 분석합니다. 영상은 한 번에 한 개만 검사합니다. YouTube 자동 가져오기는 아직 연결되지 않아 영상 파일을 직접 선택해야 합니다. 글·PDF·DOCX는 분석 대상이 아닙니다.

문제가 생겼을 때

처음 실행할 때 오래 걸립니다.

처음에는 약 41MB 모델을 내려받고 준비합니다. 상단 진행 표시가 끝날 때까지 기다려 주세요. 다운로드가 실패하면 네트워크 연결을 확인하고 새로고침하세요. 분석 시간은 기기 성능과 파일 수에 따라 달라집니다.

이미지 주소를 가져올 수 없습니다.

원본 사이트가 외부 접근을 막거나 로그인을 요구할 수 있습니다. 가져올 수 있는 이미지라면 파일로 저장한 뒤 업로드하세요. 웹페이지 주소 대신 이미지 파일 주소가 필요하며 blob:·data: 주소는 지원하지 않습니다.

HEIC·GIF 이미지가 열리지 않습니다.

현재 파일 업로드는 JPG·PNG·WEBP를 지원합니다. 지원 형식으로 내보내거나 저장한 뒤 다시 선택하세요. 파일 이름의 확장자만 바꾸면 변환되지 않습니다. 변환한 파일은 원본과 다를 수 있습니다.

파일 일부만 분석됐습니다.

여러 파일을 넣으면 최대 20개 파일을 순서대로 검사합니다. 이미지는 15MB 이하여야 합니다. 다음 파일은 다시 검사로 입력하세요.

이미지를 붙여넣을 수 없습니다.

브라우저가 클립보드 접근을 허용하지 않을 수 있습니다. 이미지를 복사한 뒤 Ctrl+V 또는 macOS의 ⌘V를 사용하거나, 파일 선택으로 올리세요. 글을 복사한 경우 이미지 분석을 시작하지 않습니다.

로그인 버튼이 ‘준비 중’입니다.

해당 제공자의 연동 설정이 완료되지 않은 상태입니다. 이미지 분석과 이 브라우저의 기록 기능은 로그인 없이 이용할 수 있습니다.

자주 묻는 질문

어떤 사진에 쓸 수 있나요?

얼굴이 또렷하게 보이는 인물 사진에 맞춰 학습한 모델입니다. 풍경·사물 사진이나 얼굴이 아주 작은 사진에서는 결과를 믿기 어렵습니다.

결과는 얼마나 정확한가요?

기존 97.8%는 학습과 중복된 사진이 포함된 1차 평가 결과여서 실사용 정확도로 볼 수 없습니다. 중복을 제거한 2차 실험에서도 처음 보는 생성기 계열에는 성능이 크게 떨어졌습니다. 모델 페이지에서 평가 조건과 한계를 확인해 주세요.

사진이 서버로 전송되나요?

아니요. 처음 한 번 모델(약 41MB)을 내려받은 뒤에는 모든 분석이 브라우저 안에서 이루어집니다. 업로드한 이미지는 어디로도 전송되지 않습니다.

기록은 어디에 저장되나요?

이 브라우저의 저장소(IndexedDB)에 검사 결과와 설명용 축소 이미지가 저장됩니다. 기록 페이지에서 끄거나 모두 삭제할 수 있습니다.

로그인하면 무엇이 달라지나요?

카카오·구글 계정으로 로그인할 수 있습니다. 현재 기록은 로그인 여부와 관계없이 이 브라우저에만 저장되며 기기 간 동기화는 제공하지 않습니다. 준비 중으로 표시된 로그인은 아직 사용할 수 없습니다.

REAL 확률이 기준선 근처예요.

사진 모델의 0.16은 분류 기준입니다. 가까운 값은 출력이 조금만 달라져도 분류가 바뀔 수 있습니다. 이 거리만으로 모델의 확신 정도를 알 수는 없습니다. 원본과 출처를 함께 확인하세요.

About

Fakit 소개

Fakit은 AI가 만든 콘텐츠를 가려내는 탐지 도구입니다. 현재 얼굴 사진 판별과 Grad-CAM 설명을 제공합니다. 영상 파일은 길이에 따라 16~64프레임(8프레임씩 구간)을 브라우저에서 분석하고, 구간 점수와 Grad-CAM을 제공합니다.
