추론 파이프라인

  1. 입력 이미지JPG · PNG · WEBP
  2. RGB 변환 · 256×256 리사이즈투명 영역은 검정으로 채움
  3. Rescaling모델 내부에서 0–255 → 정규화
  4. EfficientNetV2S backboneImageNet 사전학습 가중치
  5. GlobalAveragePooling · Dropout 0.35분류 헤드
  6. Dense · SigmoidP(real) 하나를 출력
  7. 판정P(real) ≥ 0.24 → REAL, 미만 → AI GENERATED

학습 방법

  • 2단계 학습. 먼저 backbone을 고정한 채 분류 헤드만 학습(lr 1e-3)하고, 이어서 backbone 뒷부분 일부 레이어를 풀어 낮은 학습률(lr 1e-5)로 미세조정합니다. BatchNormalization 레이어는 고정합니다.
  • 데이터 증강. 좌우 반전, 소폭 회전(±2%), 확대/축소(±5%), 대비 변화(±10%)를 적용해 데이터셋별 크롭·배치 차이를 외우지 않도록 합니다.
  • 클래스 불균형. fake / real 비율에 따라 class weight를 적용합니다.
  • 콜백. EarlyStopping, ReduceLROnPlateau, 최고 성능 가중치 저장.

평가와 기준선

  • 기준선은 검증셋에서. 판정 기준선(0.24)은 테스트셋이 아니라 검증셋에서 Macro F1이 가장 높은 값으로 고른 뒤, 모든 테스트에 동일하게 적용합니다.
  • 생성기별 테스트. 같은 분포의 ID 테스트 외에 GRAVEX, StyleGAN, FLUX·SDXL 등 생성기별 테스트셋으로 일반화 성능을 따로 봅니다. 학습에 쓰지 않은 생성기는 OOD로 표시합니다.
  • 지표. Accuracy 외에 fake 클래스 기준 Precision / Recall / F1, Macro F1, ROC-AUC를 함께 봅니다.
  • Grad-CAM. 마지막 convolution 레이어(top_conv)로 모델이 어느 부분을 보고 판단했는지 확인합니다.

결과 읽는 법

분류 결과와 사진의 실제 출처는 다를 수 있습니다.

REAL과 AI는 모델의 분류입니다

REAL

실제 얼굴 사진 범주로 분류했다는 뜻입니다. 촬영 사실, 인물의 신원, 보정 여부까지 확인한 결과는 아닙니다.

AI

AI 생성 얼굴 범주로 분류했다는 뜻입니다. 생성 프로그램이나 제작자를 알아낸 것은 아니며 실제 사진도 잘못 분류할 수 있습니다.

왜 50%가 아닌 0.24를 기준으로 하나요?

현재 모델은 REAL 점수 하나를 출력합니다. 설정된 기준선 0.24 이상은 REAL, 미만은 AI로 표시합니다. 두 범주의 숫자 중 큰 값을 고르는 방식이 아닙니다.

예: REAL 0.30 / AI 0.70 → REAL 분류

REAL 0.30이 기준선 0.24 이상이기 때문입니다. 설명을 위한 예시이며 업로드한 파일의 결과가 아닙니다.

이 점수를 해당 사진에 대한 정답 확률로 해석하면 안 됩니다. 기준선과의 거리만으로 신뢰도 등급을 만들 수도 없습니다.

예상과 다른 결과가 나왔다면

  1. 지원 대상을 확인하세요.현재 모델은 얼굴 이미지용입니다. 풍경·사물·문서 사진에 나온 숫자를 진위 판정에 사용하지 마세요.
  2. 가능하면 원본으로 다시 확인하세요.스크린샷, 재저장, 필터·보정에 따라 입력이 달라집니다. 원본과 편집본의 결과 차이 자체가 조작의 증거는 아닙니다.
  3. 최초 게시물과 제작 경로를 확인하세요.게시 날짜, 원본 파일, 촬영·제작 설명 등 별도의 정보를 함께 확인하세요. 탐지 결과만으로 타인의 제작 과정을 단정하지 마세요.

분석 화면에서 볼 수 없는 것

현재 웹 모델은 이미지 전체에 대한 점수만 반환합니다. AI로 의심되는 부위, 사용한 생성기, 생성 시각은 제공하지 않습니다. 입력 미리보기는 전처리 확인용이며 분석 근거 지도는 아닙니다.

사진과 기록 관리

현재 구현에서 어디에 어떤 정보가 남는지 안내합니다.

분석한 사진

파일은 이 브라우저에서 분석하며 Fakit 서버로 업로드하지 않습니다. 모델과 화면에 필요한 라이브러리·글꼴을 내려받을 때는 네트워크 연결을 사용합니다.

이미지 주소로 가져오기를 누르면 원본 이미지 호스트에 요청이 전달됩니다. 확장 프로그램은 선택한 이미지 주소만 Fakit으로 전달하며 페이지 전체나 로그인 쿠키를 수집하지 않습니다.

분석 기록

  • 파일명, 축소 미리보기, 결과 점수, 판정 기준선, 분석 시각이 이 브라우저에 저장됩니다. 축소 이미지에도 얼굴 등 식별 가능한 정보가 남을 수 있습니다.
  • 최대 200건을 보관하며 초과하면 오래된 기록부터 제외합니다.
  • ‘기록 저장’을 끄면 이후 기록을 저장하지 않습니다. 이미 저장된 기록까지 지워지지는 않습니다.
  • 로그아웃해도 기록은 남습니다. 같은 브라우저를 공유하는 다른 사람이 볼 수 있습니다.
  • 기록 페이지에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 삭제 후 복구 기능은 없습니다.
기록 관리

소셜 로그인

카카오·네이버·구글에서 계정 식별자와 표시 이름을 받아 로그인 상태를 관리합니다. 로그인했다고 이미지 기록이 계정에 업로드되거나 다른 기기로 동기화되지는 않습니다.

현재 서버는 로그인 정보를 메모리에 보관하며 세션은 8시간 후 만료됩니다. 서버를 다시 시작해도 로그인 상태가 해제됩니다. 서비스 로그아웃은 제공자 계정 연결 해제와 다릅니다.

사용 방법과 문제 해결

파일 선택, 붙여넣기, 이미지 주소 가져오기를 지원합니다.

이미지 올리는 세 가지 방법

드래그

끌어다 놓기

탐색기나 다른 창에서 사진을 파일 입력 영역에 끌어다 놓으면 됩니다. 여러 파일을 놓으면 최대 20개 파일을 순서대로 검사합니다.

붙여넣기

Ctrl + V

화면 캡처(Win+Shift+S)나 복사한 이미지를 페이지에서 바로 붙여넣습니다. 입력창 안에서도 이미지 붙여넣기를 지원합니다.

업로드

이미지 선택

입력창 왼쪽 + 버튼으로 파일을 고릅니다. 한 번에 최대 20개, 이미지당 15MB까지 검사합니다.

파일을 구분하는 방법

같은 입력창에서 파일 종류를 확인합니다. 현재 분석 가능한 파일은 JPG·PNG·WEBP 얼굴 이미지입니다. 영상과 글·문서는 종류만 안내하며 아직 분석하지 않습니다. PDF·DOCX 안의 이미지나 글을 자동으로 추출하지 않습니다.

문제가 생겼을 때

처음 실행할 때 오래 걸립니다.

처음에는 약 41MB 모델을 내려받고 준비합니다. 상단 진행 표시가 끝날 때까지 기다려 주세요. 다운로드가 실패하면 네트워크 연결을 확인하고 새로고침하세요. 분석 시간은 기기 성능과 파일 수에 따라 달라집니다.

이미지 주소를 가져올 수 없습니다.

원본 사이트가 외부 접근을 막거나 로그인을 요구할 수 있습니다. 가져올 수 있는 이미지라면 파일로 저장한 뒤 업로드하세요. 웹페이지 주소 대신 이미지 파일 주소가 필요하며 blob:·data: 주소는 지원하지 않습니다.

HEIC·GIF 이미지가 열리지 않습니다.

현재 파일 업로드는 JPG·PNG·WEBP를 지원합니다. 지원 형식으로 내보내거나 저장한 뒤 다시 선택하세요. 파일 이름의 확장자만 바꾸면 변환되지 않습니다. 변환한 파일은 원본과 다를 수 있습니다.

파일 일부만 분석됐습니다.

여러 파일을 넣으면 최대 20개 파일을 순서대로 검사합니다. 이미지는 15MB 이하여야 합니다. 다음 파일은 다시 검사로 입력하세요.

이미지를 붙여넣을 수 없습니다.

브라우저가 클립보드 접근을 허용하지 않을 수 있습니다. 이미지를 복사한 뒤 Ctrl+V 또는 macOS의 ⌘V를 사용하거나, 파일 선택으로 올리세요. 글을 복사한 경우 이미지 분석을 시작하지 않습니다.

로그인 버튼이 ‘준비 중’입니다.

해당 제공자의 연동 설정이 완료되지 않은 상태입니다. 이미지 분석과 이 브라우저의 기록 기능은 로그인 없이 이용할 수 있습니다.

자주 묻는 질문

어떤 사진에 쓸 수 있나요?

얼굴이 또렷하게 보이는 인물 사진에 맞춰 학습한 모델입니다. 풍경·사물 사진이나 얼굴이 아주 작은 사진에서는 결과를 믿기 어렵습니다.

결과는 얼마나 정확한가요?

테스트셋 기준 정확도 97.8%, ROC-AUC 99.8%입니다. 다만 학습에 포함되지 않은 최신 생성기나 보정이 강한 사진은 틀릴 수 있어 참고용으로만 사용해 주세요.

사진이 서버로 전송되나요?

아니요. 처음 한 번 모델(약 41MB)을 내려받은 뒤에는 모든 분석이 브라우저 안에서 이루어집니다. 업로드한 이미지는 어디로도 전송되지 않습니다.

기록은 어디에 저장되나요?

이 브라우저의 저장소(localStorage)에 축소된 미리보기와 판정 결과만 저장됩니다. 기록 페이지에서 끄거나 모두 삭제할 수 있습니다.

로그인하면 무엇이 달라지나요?

카카오·네이버·구글 계정으로 로그인할 수 있습니다. 현재 기록은 로그인 여부와 관계없이 이 브라우저에만 저장되며 기기 간 동기화는 제공하지 않습니다. 준비 중으로 표시된 로그인은 아직 사용할 수 없습니다.

REAL 확률이 기준선 근처예요.
