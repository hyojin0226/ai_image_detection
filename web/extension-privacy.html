Fakit으로 돌아가기

확장 프로그램 개인정보 안내

적용일: 2026년 11월 2일 · 버전 0.2.0

사용자가 선택한 이미지 주소만 전달합니다

이미지를 우클릭해 ‘Fakit으로 이미지 가져오기’를 선택하면 해당 이미지의 HTTP 또는 HTTPS 주소를 Fakit 페이지로 전달합니다. 주소는 URL의 # 뒤에 담기므로 Fakit 서버 요청에는 포함되지 않습니다. Fakit 페이지는 입력을 처리한 뒤 주소창에서 이를 제거합니다.

권한과 저장

확장 프로그램은 이미지 우클릭 메뉴를 위한 contextMenus 권한만 사용합니다. 방문 기록·페이지 본문·쿠키를 읽지 않고, 자체 저장소나 분석·광고 도구를 사용하지 않습니다. 원격 실행 코드를 불러오지 않습니다.

Fakit 웹사이트에서의 처리

이미지를 가져올 때 브라우저가 원본 이미지 서버에 요청하므로 원본 서버에는 IP 주소와 요청한 이미지 주소가 전달됩니다. 로그인 쿠키와 리퍼러를 보내지 않도록 요청합니다. 이미지 분석은 기기 안에서 진행됩니다. 분석 기록은 해당 브라우저에 저장되며 사이트의 기록 메뉴에서 삭제할 수 있습니다. 소셜 로그인은 선택사항이고 계정 식별자와 표시 이름을 Fakit 서버에서 처리합니다.
