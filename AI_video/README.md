# AI 영상 분류 모델

**v1.0.0 · 64프레임 + Grad-CAM · 연구용 최종 프로젝트 버전**

3~40초 영상의 실제 촬영 / AI 생성을 추정하는 프로그램이다. 기존 EfficientNetV2S를 고정하고, 영상 특징을 집계하는 RBF 분류기 2개의 평균 점수를 사용한다. 최종 영상 분류 부분은 GRU가 아니다. 임계값은 **0.5**이다.

## 웹사이트에서 분석하기

**[AI 영상 분석 사이트](https://duhyeon-ai-video.vercel.app)에서 접속한 사람의 브라우저로 분석한다. 운영자 노트북이나 모델 분석 서버를 켤 필요가 없다.**

- 영상 파일은 업로드하지 않는다. 브라우저에서 64개 시점 추출, 기존 EfficientNetV2S 특징, 두 RBF 점수, Grad-CAM을 계산한다. 주요 8개와 나머지 56개를 확인할 수 있다.
- 파일 분석은 서버 계산·Blob 업로드 횟수 한도를 사용하지 않는다. 처음에는 약 55 MB의 모델을 내려받으며, 웹호스팅의 파일 전송 한도는 별개이다. 속도는 접속한 기기 성능에 따라 달라진다.
- 입력은 3~40초, 최대 90 MB이며 브라우저에서 재생 가능한 코덱이어야 한다. 90 MB는 프로그램의 입력 기준이다.
- **YouTube 주소 자동 분석은 미완료이다.** 주소 붙여넣기 → 분석 버튼 → 정상 공개 원본 요청 → 브라우저 분석으로 연결했지만, 실제 시험에서 YouTube의 봇 확인으로 원본 요청이 거절됐다. 이 상태를 작동하는 기능으로 보장하지 않는다. 파일 선택이나 탭 공유로 대신 처리하지 않으며 접근 제한을 우회하지 않는다.
- 접근이 거절되면 YouTube 공식 페이지를 여는 확인 단계를 표시한다. 사용자가 사이트로 돌아오면 원본 연결을 한 번 다시 확인하며 수동 재확인 버튼도 제공한다. 브라우저에서 확인했다는 이유만으로 인증 성공을 표시하지 않는다. 브라우저의 로그인·사람 확인 결과가 서버에 전달되는 기능은 아니며, 원본이 실제 수신된 경우에만 분석으로 진행한다.
- 기존 최종 가중치와 임계값 0.5는 유지한다. 동일 RGB 입력에서 TensorFlow.js 특징·영상 점수·공간 기울기 동등성을 확인했다. 브라우저 동영상 디코딩·크기 조정은 FFmpeg와 다를 수 있어 Python 버전과 결과가 달라질 수 있으며 브라우저 방식의 정확도는 별도 검증 전이다.
- `웹사이트 켜기.bat`은 같은 사이트를 연다. 웹사이트 사용을 위해 실행할 필요는 없다. GitHub 자동 배포 연결은 보류 상태이다.

개발자가 웹 파일을 준비할 때는 `AI_video` 폴더에서 `python tools/package_browser_model.py`를 실행한다(Python과 NumPy 필요). 기존 고정 가중치에서 `deploy/site/model/`을 생성하고, 고정 버전 TensorFlow.js와 라이선스를 `deploy/site/vendor/`에 준비한다. 이 생성 파일은 Git에 중복 저장하지 않으며 Vercel 사이트 배포에는 포함한다. `deploy/site/`에 웹 화면·브라우저 계산 코드가 있고, `deploy/cloud/api/source.py`는 YouTube 공개 원본을 정상 요청하는 연결이다. 파일 분석에는 이 연결 서버를 사용하지 않는다.

## 개인 컴퓨터에서 직접 판별하기 · Windows

**GitHub에서 이 브랜치를 pull한 뒤 `AI_video/실행.exe`를 더블클릭하면 된다. 별도 다운로드 링크, Python 설치, 명령어 입력, 모델 학습은 필요 없다.**

1. `study/KongDuHyun` 브랜치의 폴더 전체를 clone 또는 pull한다. Download ZIP으로 받았다면 압축을 푼다.
2. `AI_video` 폴더 안의 **`실행.exe`**를 더블클릭한다. 처음 한 번은 함께 포함된 실행 환경을 자동으로 준비한다.
3. **영상 파일 선택** 또는 **YouTube Shorts 주소 입력** → **분석 시작**을 누른다.
4. 주요 프레임 8개의 원본·Grad-CAM을 확인한다. **세부사항**에서 나머지 프레임을 확인한다.

Windows 10/11 **Intel·AMD 64비트**용이다. 필요한 Python·모델·영상 처리 도구·Node.js는 `desktop/runtime/`에 함께 들어 있다. 실행 시 인터넷에서 프로그램을 추가로 받지 않는다. **`실행.exe`와 `desktop` 폴더를 분리하거나 `desktop/runtime` 파일을 지우지 않는다.** 로컬 파일은 인터넷 없이 분석할 수 있고, Shorts 주소는 인터넷과 YouTube의 정상적인 공개 다운로드 접근이 필요하다. 다른 사람이 자신의 컴퓨터에서 실행하면 제작자의 노트북은 켜 두지 않아도 된다.

전체 실행 환경은 약 506 MB이다. GitHub 파일 크기 제한에 맞춰 하위 폴더에 나누어 보관했으며, 사용자가 이 파일들을 직접 열거나 합칠 필요는 없다.

첫 실행에 준비된 파일과 분석 결과는 `%LOCALAPPDATA%\AI-Video-Classifier\`에 저장한다. 수 GB의 여유 공간이 필요하며, 첫 준비가 끝난 뒤에는 같은 실행 파일을 클릭해 다시 연다. 실행 파일은 서명되지 않아 Windows에서 실행 확인을 표시할 수 있다.

## 동작과 결과

`영상 → 8개 구간 × 8장 → 비율 유지·256×256 RGB → EfficientNetV2S → 구간 특징·RBF 점수 → 구간 평균 → 판별`

- 입력은 **3~40초, 최대 90 MB**이며 세로 영상을 우선 대상으로 한다. 로컬 가로 영상도 비율을 유지한다.
- 메인에는 최종 점수에 대한 민감도가 큰 **주요 프레임 8개**, **세부사항**에는 나머지 **56개**와 구간별 점수를 표시한다.
- 모든 분석 프레임의 원본과 **Grad-CAM**을 나란히 표시한다. 클릭하면 확대한다. 실제 촬영으로 판별하면 실제 촬영 판단을 지지하는 영역을 표시한다.
- 검은 화면만 제외한다. 유효 시점이 부족한 구간은 미분석으로 명시하며, 이 경우 분석 프레임 수가 64개보다 적을 수 있다.
- 약 16초 개발용 영상 한 개에서 64프레임·Grad-CAM 생성에 약 **54초**가 걸렸다. 40초 영상은 아직 직접 시간 측정하지 않았다.

| 분석 방식 | 평가 자료 | 정확도 | 해석 |
| --- | --- | ---: | --- |
| 종전 전체 8프레임 | 검증 200개 | 90.0% | 모델 선택에 사용한 개발 검증 |
| 종전 전체 8프레임 | 기존 Test 1,000개 재비교 | 81.5% | 실제 오탐률 11.6%. 새 독립 시험이 아닌 참고 비교 |
| **현재 64프레임** | 기능 확인 완료 | **미측정** | 64개 Grad-CAM, 메인 8개·세부 56개 생성 확인 |

**한계:** 프로젝트 버전 확정은 목표 정확도 95% 달성을 뜻하지 않는다. 종전 정확도를 64프레임 방식에 적용할 수 없다. AI 시험 자료는 Sora에 한정되고, 30초 초과 AI 자료가 없어 해당 구간의 양쪽 분류 성능은 미검증이다. Grad-CAM은 합성 위치나 생성 사실의 증명이 아니며 프레임끼리 색의 진하기를 비교할 수 없다. AI 점수는 보정된 정답 확률이 아니다.

## 구조

```text
AI_video/
├── 실행.exe                    # 사용자는 이 파일만 더블클릭
├── start_64frame_model.bat       # 실행
├── AI_video.code-workspace      # VS Code 실행·파일 검사
├── src/                        # 화면·64프레임 분석·필수 연결 모듈
├── desktop/                    # 실행 환경과 Windows 실행 파일 제작 소스
│   └── runtime/                # 포함된 실행 환경. 직접 열지 않음
├── configs/                    # 최종 설정
├── releases/v1.0.0.json         # 고정한 코드·가중치 해시와 모델 규격
├── tools/release.py            # 파일 검사·가중치 ZIP 생성
├── tests/                      # 분할·점수·Grad-CAM 검사
├── requirements.txt
├── models/final_research_v1/    # 실행에 필요한 학습된 가중치 포함
└── data/sample/                # train / valid / test → real / fake
```

학습: 실제 500개·AI 500개 / 검증: 실제 100개·AI 100개 / 기존 시험: 실제 500개·AI 500개이다. `data/sample/*.csv`에 배정 목록을 기록했다. 시험 자료는 학습에 사용하지 않았다.

원본 영상·캐시·과거 가중치·분석 결과·개인 환경은 GitHub 업로드에서 제외한다. 실행에 필요한 최종 가중치만 포함한다. 분석 결과는 `.local/analyzed_frames64/`에 저장된다. 과거 코드는 `archive/`에 로컬 보관하며, 오래된 안내 문서는 삭제했다. `start_final_model.bat`은 종전 8프레임 호환 실행 파일로 보존한다.

코드는 상위 프로젝트의 MIT 라이선스를 따른다. 데이터·가중치에는 별도의 재배포 조건이 적용될 수 있으므로 MIT를 일괄 적용하지 않는다. 이 브랜치에는 실행 코드와 최종 가중치를 함께 제공한다. 원본 학습·시험 영상은 재배포하지 않는다.
