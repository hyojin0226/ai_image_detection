# Fakit — AI 생성 얼굴 이미지·영상 탐지

사진이나 영상 속 얼굴이 **실제(REAL)인지 AI가 만든 것(FAKE)인지** 판별하는 딥러닝 프로젝트입니다.
학습한 모델을 **웹사이트**와 **크롬 확장 프로그램**에 넣어, 이미지를 외부 서버로 보내지 않고 브라우저 안에서 바로 검사합니다.

**웹사이트:** https://fakit-lens.vercel.app

| 무엇을 | 어떻게 |
|---|---|
| 사진 검사 | 얼굴을 찾아 잘라낸 뒤 EfficientNetV2-S로 REAL / FAKE 판정 + Grad-CAM으로 판단 근거 표시 |
| 영상 검사 | 영상 길이에 따라 16·32·48·64프레임을 뽑아 영상 전용 분류기로 AI 생성 여부 판정 |
| 크롬 확장 | 보고 있는 웹페이지(인스타그램 등)의 얼굴 이미지에 REAL / FAKE 배지 표시 |
| 연구 | 처음 보는 생성기 일반화(LOGO), SNS 압축·축소 강건성, 보정 사진 오탐 분석 |

---

## 1. 웹사이트 (Fakit)

https://fakit-lens.vercel.app

- **사진 검사**: 사진을 올리면 얼굴마다 REAL 점수와 판정을 보여줍니다. 여러 장을 한 번에 넣을 수 있고 결과는 기록에 남습니다.
- **영상 검사**: 3~40초 MP4 / WebM 영상을 브라우저에서 분석합니다. 구간별 점수와 주요 프레임의 Grad-CAM을 함께 보여줍니다.
- **Grad-CAM**: 모델이 판단할 때 참고한 얼굴 영역을 색으로 표시합니다. 붉은 부분이 곧 조작된 부분이라는 뜻은 아닙니다.
- **개인정보**: 모든 추론은 브라우저 안(ONNX Runtime Web, TensorFlow.js)에서 일어나며 파일을 서버로 보내지 않습니다.

### 사진 판정 과정

```
사진 → BlazeFace 얼굴 검출 → 얼굴 주변 2배 영역 정사각 crop → 256×256
     → JPEG 품질 90 재인코딩 → 정규화(평균·표준편차 0.5) → 320×320 확대
     → EfficientNetV2-S → P(real) ≥ 0.34 이면 REAL, 미만이면 AI
```

얼굴을 찾지 못하면 "판단 불가"로 표시합니다.

## 2. 최종 모델

**EfficientNetV2-S** (ImageNet-21k 사전학습, `tf_efficientnetv2_s.in21k_ft_in1k`)

- **데이터**: GAN(StyleGAN 등), diffusion(FLUX, SD, SDXL 등), 얼굴 조작(manip) 세 계열의 가짜 얼굴과 실제 얼굴(FFHQ 등)
- **의사 fake**: 실제 사진을 Stable Diffusion VAE로 재구성한 이미지를 fake로 함께 학습 → 처음 보는 diffusion 생성기에 대한 일반화 향상
- **열화 증강**: 축소(0.4~1.0배), 블러, JPEG 압축을 학습에 섞어 SNS에 올라간 사진에도 견디도록 함
- **학습 설정** (valid 점수로만 선택): 8 epoch, EMA 0.999, drop path 0.2, 얼굴 crop 이미지 50% 혼합, 입력 320
- **판정 기준**: 얼굴 crop 0.34 / 이미지 전체 0.52 (valid Macro F1 기준)

### 성능 (얼굴 crop 기준)

| 평가 | AUC | 정확도 | fake recall | real recall |
|---|---|---|---|---|
| 같은 분포 test 6,000장 | 0.998 | 97.6% | 0.965 | 0.988 |
| 같은 분포 test, JPEG 품질 50 | 0.997 | 96.9% | 0.971 | 0.967 |
| **학습에 쓰지 않은 추가 test 20,000장** | **0.994** | **95.5%** | 0.937 | 0.973 |

**SNS 강건성** (추가 test 20,000장 AUC): 원본 0.994 · JPEG 50 0.989 · 0.5배 축소 0.992 · 블러 σ1.0 0.993

**이전 사진 모델(ConvNeXt-T)과 비교** (같은 학습 방식, 추가 test 20,000장)

| | ConvNeXt-T | EfficientNetV2-S (최종) |
|---|---|---|
| AUC | 0.990 | **0.994** |
| 균형 정확도 | 94.6% | **95.5%** |
| real recall | 95.4% | **97.3%** |
| JPEG 50 균형 정확도 | 91.7% | **93.2%** |
| 모델 파일 (브라우저용 ONNX) | 56 MB | **42 MB** |

## 3. 연구 결과

### 처음 보는 생성기 일반화 (LOGO: 계열 하나를 빼고 학습 → 뺀 계열로 테스트)

| 의사 fake | diffusion | GAN | 얼굴 조작 |
|---|---|---|---|
| 기준선 (튜닝 전, 의사 fake 없음) | 0.728 | 0.473 | 0.458 |
| 의사 fake 없음 | 0.722 | 0.489 | 0.393 |
| **VAE (배포 모델과 같은 조합)** | **0.876** | 0.530 | 0.429 |
| SBI | 0.907 | 0.383 | 0.527 |
| VAE + SBI | 0.935 | 0.466 | 0.507 |

- VAE 의사 fake는 **처음 보는 diffusion 생성기** AUC를 0.73 → 0.88로 끌어올렸습니다.
- 반대로 처음 보는 GAN·얼굴 조작은 여전히 0.5 안팎이라, **새로운 계열의 생성기에는 아직 약합니다.**
- AUC가 높아도 정해진 기준값에서 실제로 잡아내는 비율(fake recall)은 낮을 수 있어 함께 봐야 합니다.

### 보정 사진 오탐 (실제 사진 300장에 보정 적용 → FAKE로 잘못 본 비율)

| 보정 | 약 | 중 | 강 |
|---|---|---|---|
| 피부 보정 | 0.0% | 4.3% | 12.3% |
| 눈 키우기 | 0.0% | 0.0% | 0.0% |
| 얼굴 축소 | 0.0% | 0.0% | 0.3% |
| 뷰티 조합 | 5.7% | 14.3% | – |

피부를 매끈하게 만드는 보정이 강할수록 AI 생성으로 오인하는 경우가 늘어납니다.

### 얼굴 crop의 효과

얼굴이 작게 찍힌 사진(900×700 배경 속 200px 얼굴, 400장)에서 이미지 전체를 보면 정확도 56%에 그쳤지만,
얼굴을 찾아 잘라낸 뒤 판정하면 **98%** 까지 올라갑니다. 성능 차이는 모델보다 **얼굴 crop 처리**에서 나옵니다.

## 4. 영상 검사

- 3~40초 영상에서 길이에 따라 프레임을 고르게 추출합니다: 10초 이하 16개 · 20초 이하 32개 · 30초 이하 48개 · 그 이상 64개
- 프레임마다 EfficientNetV2-S 특징을 뽑고, 시간 통계(772차원)로 모은 뒤 RBF 분류기 두 개의 평균으로 판정합니다.
- AI 점수 0.5 이상이면 AI 생성으로 분류합니다.
- 시험 영상 1,000개(실제 500 · Sora AI 500)에서 정확도 약 80%. 실제 영상을 AI로 잘못 보는 경우가 약 19% 있어 결과는 참고용으로 보는 것이 좋습니다.

## 5. 크롬 확장 프로그램 (AI Face Detector)

페이지 우측 하단의 **AI 얼굴 스캔** 버튼을 누르면 화면 속 얼굴 이미지를 찾아 `REAL 94%` / `FAKE 87%` / `판단 불가` 배지를 붙입니다.
배지를 누르면 잘라낸 얼굴과 Grad-CAM을 보여줍니다. 모델이 확장 안에 들어 있어 서버 없이 동작하고 이미지를 밖으로 보내지 않습니다.

설치: `chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램 로드** → `extension/` 폴더 선택
(모델 파일 포함 빌드: `web_model/build_extension.py`)

## 6. 저장소 구성

| 브랜치 | 내용 |
|---|---|
| `main` | 프로젝트 소개 (이 문서) |
| `develop` | 최종 모델, 로컬 추론 서버, 크롬 확장, 브라우저용 모델 변환, 실험 결과 |
| `fakit-preview` | 배포 중인 웹사이트 (Fakit) |
| `study/KongDuHyun` | 영상 탐지 모델 |
| `feature/generalization-study` | 2차 일반화 실험 (모델 비교, LOGO) |

`develop` 브랜치 주요 폴더:

```
efficientnetv2s_fake_face_FINAL_locaL.ipynb   1차 학습 노트북 (Keras)
server/            FastAPI 로컬 추론 서버 (얼굴 검출, 예측, Grad-CAM, ELA)
extension/         크롬 확장 (Manifest V3, 브라우저 안 추론)
web_model/         최종 모델 → ONNX 변환·검증, 사이트 모델 비교
experiments/       보정 사진 실험 스크립트
results/           실험 결과 CSV와 발표용 차트
  phase9_efficientnet/   최종 모델 튜닝·LOGO·강건성
  experiment_b/          보정 사진 오탐
  presentation_charts/   발표 그래프
```

### 로컬 서버로 실행하기

```bat
:: develop 브랜치에서, 모델 파일(server/models/efficientnetv2s_fake_face.pt)을 넣은 뒤
server\run_server.bat
```

http://127.0.0.1:8000/health 로 확인합니다. 자세한 내용은 `develop` 브랜치의 `server/README.md`를 보세요.
모델 가중치 파일(.pt, .onnx)은 용량 때문에 저장소에 올리지 않습니다.

## 7. 한계

- 처음 보는 GAN·얼굴 조작 계열에 대한 일반화는 아직 약합니다 (LOGO AUC 0.4~0.5대).
- 강한 피부 보정·뷰티 필터를 거친 실제 사진을 AI로 오인할 수 있습니다.
- 얼굴이 없거나 너무 작으면 판정하지 않습니다.
- 점수는 모델 출력값이며 보정된 확률이 아닙니다. Grad-CAM은 판단 근거를 보여줄 뿐 조작 위치를 증명하지 않습니다.
