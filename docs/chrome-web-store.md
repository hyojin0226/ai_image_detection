# Chrome 웹 스토어 제출 자료 — Fakit 0.2.0

- 이름: Fakit — 이미지 주소 가져오기
- 요약: 웹페이지의 이미지를 우클릭해 Fakit으로 주소를 가져옵니다.
- 단일 목적: 사용자가 선택한 웹 이미지의 주소를 Fakit 이미지 검사 화면으로 전달합니다.
- contextMenus 권한 사유: 이미지 우클릭 메뉴에 Fakit 가져오기 항목을 표시합니다.
- 원격 코드: 없음. 확장 프로그램은 로컬 service worker와 HTML/CSS만 실행합니다.
- 홈페이지: https://fakit-integrated.onrender.com/
- 개인정보 안내: https://fakit-integrated.onrender.com/extension-privacy.html
- 문의: https://github.com/hyojin0226/ai_image_detection/issues

## 상세 설명
웹페이지에서 확인하고 싶은 사진을 우클릭해 ‘Fakit으로 이미지 가져오기’를 선택하세요. Fakit에서 이미지 주소를 가져와 분석을 진행할 수 있습니다. 확장 프로그램 아이콘을 누르면 사용 방법과 사이트 바로가기를 확인할 수 있습니다.

확장 프로그램은 이미지 주소 전달 도구이며 자체적으로 진위 여부를 판정하지 않습니다. 분석 결과는 참고용입니다. 원본 사이트가 외부 이미지 접근을 허용하지 않으면 사진을 저장한 뒤 직접 첨부해 주세요. 로그인 전용 이미지, blob/data 주소, CSS 배경 이미지는 지원하지 않을 수 있습니다.

방문 기록이나 쿠키 접근 권한을 요청하지 않으며 추적·광고 코드를 포함하지 않습니다. 이미지 URL은 주소의 fragment로 전달되어 Fakit 서버 요청에 포함되지 않습니다. 가져오기 시 원본 이미지 서버로 브라우저 요청이 전송됩니다.

## 심사자가 확인할 순서
1. 확장 프로그램을 설치합니다. 별도 로그인은 필요하지 않습니다.
2. 공개 웹페이지의 일반 이미지를 우클릭합니다.
3. Fakit으로 이미지 가져오기를 선택합니다.
4. 열린 Fakit에서 주소를 확인하고 가져오기를 진행합니다.
5. CORS 허용 이미지의 분석 결과 또는 가져오기 오류 안내를 확인합니다.
6. 툴바 아이콘으로 안내 팝업과 개인정보 안내를 확인합니다.

## 제출 전 남은 작업
개발자 계정 등록/본인 인증 및 필요한 수수료 결제, 실제 Chrome 설치 테스트, 실제 사용 화면 스크린샷, 스토어 개인정보 항목 검토, 심사 제출이 필요합니다. 등록 정보는 소유자가 확인해야 합니다. 현재 ZIP은 스토어 승인 또는 설치 테스트 완료를 의미하지 않습니다.
