## 적용한 부분

- 글 분석 메뉴와 안내를 제거하고 사진/영상 링크 입력으로 변경.
- 긴 직접 이미지 URL도 기존 CORS 이미지 가져오기 경로로 처리.
- YouTube watch/shorts/youtu.be를 정확한 호스트와 영상 ID로 구분. 이 단계는 주소 인식이며 영상 내용 검사 또는 존재 여부 검증이 아님.
- 사진 결과 아래에 실제 Grad-CAM 표시. 브라우저에서만 계산하며 새 서비스/라이브러리는 추가하지 않음.
- TF.js 그래프 변환으로 top_conv와 BN이 융합되어, 최종 공간 활성층 `top_activation`(8×8)을 사용. 연구 코드의 top_conv 지도와 픽셀 단위 동일성을 주장하지 않음.
- GAP/GMP → Dense → BN → ReLU → real logit을 재구성하고 원본 모델 점수와 오차 0.001 이하인지 매번 검증. 불일치/미지원 환경이면 설명만 실패 처리하고 실제 판별 점수는 유지.
- Grad-CAM은 위조 영역 검출/정확도 지표가 아니다. 현재 검사 및 다중 첨부 결과에서 제공하며 과거 기록에는 설명 이미지를 저장하지 않음.

## 영상 연결에 필요한 전달물

1. 모델 가중치 또는 추론 API와 실행 코드, 패키지 버전.
2. 얼굴 검출/추적/크롭 방식, 얼굴이 없거나 여러 명일 때 처리.
3. 프레임 추출 간격·상한, RGB/크기/정규화.
4. 클래스 방향·임계값, 프레임 점수를 영상 결과로 합치는 검증된 규칙.
5. 유튜브 원본 확보 경로, 비공개/삭제/지역 제한 처리, 전송·보관 범위.

사진 모델에 영상 전체 프레임을 넣는 것만으로 영상 전용 모델 또는 얼굴 검출을 구현했다고 간주하지 않는다. 유튜브 썸네일도 영상 분석의 대체물이 아니다.
